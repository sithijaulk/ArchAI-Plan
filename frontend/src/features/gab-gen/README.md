# GAB-Gen Frontend Feature Module

Component 1: Geo-Spatial AI Blueprint Generator (ArchAI-Plan)

## Future Responsibilities

- **Input UI**: Deed/survey file upload (JPG, JPEG, PNG, PDF) with preview, land metadata input (extent, unit, perches/sqft, drawing scale ratio), building requirements (storeys, bedrooms, bathrooms, living areas, kitchen, dining, parking/garage, stair, balcony, additional amenities, budget/area preferences).
- **Workflow UI**: Multi-stage workflow state management (input, processing, validation, output).
- **Preview**: Source image preview, vector land polygon visualization, buildable footprint preview, 2D plan renderer, 3D JSON-driven preview, Master JSON inspector.
- **Exports**: Export functionality (PNG, PDF, JSON).
