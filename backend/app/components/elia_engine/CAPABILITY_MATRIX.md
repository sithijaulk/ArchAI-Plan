# ELIA Engine — Product Capability Matrix

> Component 4: Eco-Spatial Landscape Intelligence (ELIA Engine)
> Architecture Stage: Panel Feedback & Complete Customer Customization Implementation

This matrix records the intended product behavior, required upstream inputs, client requirements, existing implementation evidence, output ownership, missing-data behavior, current status, and target stage for each exterior design capability.

Statuses:
- **Implemented**: Implemented and verified in the current codebase.
- **Partially implemented**: Core logic in place; specific sub-features or model integrations deferred.
- **Contract defined; implementation pending**: Contract, data model, and interface established; full operational logic deferred to later stages.
- **Blocked by unavailable upstream data**: Feature requires upstream component inputs not currently produced by the established flow.

### Upstream Input Dependencies Summary

1. **Authoritative Survey & Site Geometry (Component 1 & 2)**:
   - `land_boundary_polygon` (or `land_info.mathematical_polygon` / `boundary_polygon`)
   - `house_exterior_polygon` (or `buildable_footprint.house_exterior_polygon` / `house.exterior_polygon`)
   - `road_facing` / `road_access_edge`
   - `calculated_north_bearing` / `north_angle`
   - Length unit declaration (`units`: "m", "ft", etc.)
2. **Utilities & Existing Structures (Component 2 & 3)**:
   - `utilities.water_well` / `septic_tank` (with coordinates in `position`, `center`, or `x`/`y`)
   - `existing_garage` / `existing_gate` (if present on site)
3. **Elevated & Roof Geometries (Component 2 & 3 - Required for Solar & Balcony Greenery)**:
   - Balcony / terrace polygon outlines with `elevation_m` or `floor_id`
   - Roof outline, slope angle, and ridge orientation (required for photovoltaic layout)
