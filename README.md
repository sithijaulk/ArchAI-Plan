## 📌 Executive Summary

**ESAI-Engine (Ergonomic Spatial Artificial Intelligence Engine)** is Component 3 of the **ArchAI-Plan** platform. It is dedicated to intelligent interior space planning, furniture layout synthesis, and ergonomic optimization for residential buildings.

Taking structural room definitions, door/window openings, and floor plans generated by GAB-Gen and rectified by VSAI-Rectifier, ESAI-Engine applies evolutionary optimization algorithms (PyGAD) alongside strict human-factors ergonomic standards to produce optimized, functional, and aesthetically viable interior layouts. It generates ranked design alternatives, evaluates fitness criteria, manages asset catalogs, and synthesizes layout proposals back into the project's **Master JSON** document.

---

## 🚀 Key Responsibilities & Capabilities

1. **Structural Input Parsing & Normalization:**
   - Ingestion of structural geometry (room boundaries, walls, doors, windows, and passage openings).
   - Canonical spatial normalization converting measurements across diverse units (`m`, `cm`, `mm`, `ft`, `in`) to standardized base meters.
   - Dynamic calculation of room clearances, entry/exit circulation corridors, and natural lighting vectors.

2. **Client Preferences & Room Requirement Resolution:**
   - Multi-tiered client preference hierarchy (Project-level, Room-level, and Asset-level customization).
   - Dynamic mapping of user-selected interior styles, color palettes, material finishes, and budget tiers to catalog items.
   - Support for specialized functional activity zones within rooms (e.g., sleeping, study/work, storage, entertainment).

3. **Asset Catalog & Ergonomic Knowledge Base:**
   - Standardized 2D/3D furniture asset repository with realistic bounding boxes, clearance buffers, and placement orientations.
   - Built-in ergonomic standards rules (minimum pathway widths, reach envelopes, bed-to-wall clearances, door swing zones, and TV viewing angles).
   - Finish and material catalogs (flooring, wall treatments, trims).

4. **Evolutionary Optimization (PyGAD Optimizer):**
   - Genetic Algorithm (GA) driven asset layout placement and orientation optimization.
   - Multi-objective fitness function scoring:
     - Hard constraint enforcement (no asset overlapping, door/window clearance preservation, boundary containment).
     - Soft ergonomic objectives (circulation flow, line-of-sight, balance, natural light accessibility, aesthetic grouping).
   - Generation of distinct, ranked design alternatives for client selection.

5. **Reporting, Validation & Master JSON Persistence:**
   - Comprehensive layout validation reporting compliance scores, clearance violations, and ergonomic warnings.
   - Professional PDF report generation summarizing room layouts, bill of quantities (BOQ), and ergonomic compliance metrics.
   - Non-destructive updates to the project's **Master JSON** document under `interior_layout` and `processing.esai_engine`.

## 🏗️ Architectural Sub-Modules

Located at `backend/app/components/esai_engine/`:

| Sub-module / File | Responsibility |
|---|---|
| `parser.py` | Parses room polygons, door/window placements, and structural data from the Master JSON. |
| `normalizer.py` | Normalizes coordinates and converts diverse imperial/metric units into canonical meters. |
| `contracts.py` | Pydantic DTOs, schemas, enums, and typed contracts for assets, requirements, and layouts. |
| `catalog.py` | Furniture asset repository, dimensions, clearance profiles, and finish asset definitions. |
| `rules.py` | Ergonomic standards, human factors guidelines, and dimensional clearance rules. |
| `room_knowledge.py` | Domain knowledge regarding standard room types, functional zones, and required asset groupings. |
| `resolver.py` | Resolves client style preferences, room requirements, and maps them to concrete catalog assets. |
| `optimizer/` | PyGAD-based genetic algorithm engine, fitness functions, chromosomes, and baseline comparisons. |
| `generation/` | Room and building layout generators orchestrating sequential asset placements. |
| `validators.py` | Geometric collision detection, boundary containment checks, and circulation path validators. |
| `reporting/` | Generates detailed evaluation summaries and exportable PDF design reports. |
| `persistence.py` | Manages transactional persistence, history tracking, alternative layouts, and Master JSON synchronization. |
| `service.py` | High-level orchestrator coordinating the entire ESAI generation and evaluation pipeline. |

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.11+
- **Optimization:** PyGAD (Genetic Algorithm framework), NumPy, SciPy
- **Geometry & Spatial Checks:** Shapely (Polygon intersection, containment, buffering)
- **API Framework & Validation:** FastAPI, Pydantic v2, SQLAlchemy
- **Document Generation:** ReportLab / FPDF2 (PDF generation)
