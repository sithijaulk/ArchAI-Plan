# GAB-Gen Stage-2 Model Training & Pipeline

Component 1: Geo-Spatial AI Blueprint Generator

## Module Overview

- **ocr/**: Pretrained EasyOCR evaluation, line/text detection, survey text extraction scripts and notebooks.
- **xgboost/**: XGBoost synthetic spatial allocation model training, evaluation, scripts, and configuration files.
- **dataset_generation/**: Synthetic dataset generation scripts for spatial allocation.

Note: Model binary files (*.json, *.ubj, *.pkl, *.joblib, cache) are excluded from Git version control.
